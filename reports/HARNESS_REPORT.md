This report answers the four questions a reviewer should ask about the
video: what the lanes are, how the harness gates each step, whether the
numbers came from a real run, and how to reproduce them.

---

## 1. What the harness did

The harness compiled one task contract (`takes/binance-incident.sh`) into
four ordered lanes. Each lane owns one artifact. Before the next lane can
start, the take checks that artifact with `need_grep` or `need_file`; a
failed gate calls `die`, which stops the take. The video is rendered only
after `scripts/verify_all.py` reports `overall: ok`.

```
task contract
   ├─ lane 1  builder   → test artifact       → gate
   ├─ lane 2  reviewer  → security report     → gate
   ├─ lane 3  fixer     → exchange source     → gate
   └─ lane 4  verifier  → replay + full gate  → gate
                                                   ↓
                                             video build
```

The renderer is `build_video.py` (outside the public repository). It
re-runs `verify_all.py`, reads `reports/TEST_RESULTS.json` and
`reports/evidence/phase3-replay.json`, and refuses to record when the
overall gate is not green. The on-screen numbers are read from those
files, not typed into the scene.

The route labels describe the class of model a lane can be bound to. This
recording was produced on free/local routes: no OpenAI, Gemini, Anthropic
or DeepSeek vendor key was present. The evidence on screen is the
repository's real output, not a vendor transcript.

A lane that did not run is never presented as a lane that ran. The red
artifact is the exception that proves the rule: it is a *saved* run from
before the fix, and the video labels it as a saved artifact because the
fixed code is now installed.

## 7. Boundaries

- The real incident was an internal signing-service and EIP-7702
  compromise; this simulator is a withdrawal-control analogue, not a
  reproduction of the attack chain.
- All accounts, balances, keys, addresses and transactions are synthetic.
- No real funds, wallets, credentials, endpoints or blockchain calls.
- The four lane classes are routing roles, not a claim that a specific
  vendor model produced each artifact.
- The saved red artifact is dated evidence. The video says so on screen.
